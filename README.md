# OS Pen: draw on any screen in Windows and Android

**One tool instead of three: a screen pen, a screen recorder and a whiteboard.**

OS Pen by Snowfairy AI puts a small floating toolbar over whatever is on your screen, so you can draw, highlight and explain on top of any app: a browser, a PDF, slides, a video or a code editor.

## Why

Windows 11 has no built-in way to draw live over every app. The Snipping Tool only marks up a frozen screenshot, and PowerPoint's pen disappears the moment you switch windows. OS Pen draws over the live screen, with one shortcut.

Press **Ctrl + Shift + Space** to start drawing over any app. Press it again to go back to normal.

## What is inside

**Draw over anything**
- Pen, highlighter, eraser, text, callouts and 3D text
- Lines, arrows, rectangles, ellipses and polygons
- Smart Pen: a rough hand-drawn shape snaps into a clean one
- Select, move and duplicate what you have drawn

**Precision tools for teaching**
- On-screen ruler, protractor and compass with snap-to-angle
- Live coordinate readout
- Magnifier

**Presenting**
- Spotlight and curtain to focus attention
- Laser pointer with a trail, and cursor effects
- Screen Freeze: pause a live screen or video and explain on top of it
- Step numbers and a session timer

**Whiteboard**
- Whiteboard and blackboard modes, grid and custom backgrounds
- Multiple pages, session save and crash recovery

**Capture and record**
- Screenshot any area and edit it in the built-in editor
- Replay your drawing and export it as a GIF
- Creator Recorder (beta): screen + microphone + optional webcam overlay
- PDF export with a redact tool
- OCR to pull text from the screen

**Two devices, one board (beta)**
- A second device on the same Wi-Fi can join the same board. Local network only, no internet needed.

**Private by design**
- Your screen content stays on your device. Nothing is uploaded unless you export it.
